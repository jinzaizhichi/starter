# Nvim 快捷键速查

> 基于 NvChad + lazy.nvim，自定义快捷键在 `lua/mappings.lua`

## 通用

| 快捷键 | 模式 | 功能 |
|--------|------|------|
| `jk` | 插入 | 退出插入模式 |
| `;` | 普通 | 进入命令行模式（等价 `:`） |
| `<C-s>` | 普通 | 保存文件 |
| `<C-c>` | 普通 | 复制整个文件 |
| `<Esc>` | 普通 | 清除搜索高亮 |
| `<leader>n` | 普通 | 切换绝对行号 |
| `<leader>rn` | 普通 | 切换相对行号 |
| `<leader>ch` | 普通 | 打开快捷键速查 |
| `<leader>wK` | 普通 | 打开 WhichKey |
| `<leader>wk` | 普通 | WhichKey 关键字查询 |

---

## 自定义新快捷键

在 `lua/mappings.lua` 中添加：

```lua
map("n", "<leader>xx", "<cmd>你的命令<CR>", { desc = "功能描述" })
```

`<leader>` 默认为空格键。
